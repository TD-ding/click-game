# Click Game

一个基于 tkinter 的点击计分小游戏。

## 功能

- 点击按钮或按空格键得分
- 实时分数显示 + 最高分记录
- 30 秒限时挑战模式
- 按钮点击闪烁反馈
- 窗口自动居中

## 运行

```bash
python click-game.py
```

## 开发过程

| 轮次 | 类型 | 改动 |

| 第3轮 | feat | 用户体验优化 - 窗口居中、按钮闪烁、空格键 |
| 第4轮 | feat | 功能增强 - 最高分记录、限时挑战模式 |
