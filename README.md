# Game Projects

通过模拟真实协作开发流程完成的小游戏项目集合。

## 项目

### [Click Game](click-game.py)
一个基于 tkinter 的点击计分小游戏。

- 点击按钮或按空格键得分
- 实时分数显示 + 最高分记录
- 30 秒限时挑战模式
- 按钮点击闪烁反馈

详见 [collab-log.md](collab-log.md) 获取完整协作日志。

### [Pac-Man Game](pacman-game/)
一个基于 pygame 的吃豆人游戏。

- 4 个差异化幽灵 AI（Blinky/Pinky/Inky/Clyde）
- 多关卡系统（通关后难度递增）
- 水果道具系统
- 程序化音效
- 分数弹出动画

详见 [pacman-game/collab-log.md](pacman-game/collab-log.md) 获取完整协作日志。

## 开发流程

两个项目均通过模拟真实协作开发流程完成，共经历 5 轮迭代：

| 轮次 | 类型 | 说明 |
|------|------|------|
| 第1轮 | feat | 初始版本 |
| 第2轮 | refactor/fix | 代码质量优化 / Bug修复 |
| 第3轮 | feat | 用户体验优化 |
| 第4轮 | feat | 功能增强 |
| 第5轮 | fix | Bug 修复 |
